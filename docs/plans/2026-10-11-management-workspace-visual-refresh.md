# 管理工作台视觉刷新方案

核对时间：2026-10-11（Asia/Shanghai）

## 目标

在保留管理工作台现有项目切换、筛选、创建、删除、迁移、成员、AGENTS 规则和审批行为的前提下，恢复更克制、统一的产品视觉：减少重复浅蓝色卡片，强化主次层级，压缩无效留白，让左侧项目导航与右侧详情成为清晰的工作区。

## 实施边界

- 调整 `smartbrain-dashboard/app/(with-shell)/admin/page.tsx` 的页面结构标记与 `smartbrain-dashboard/app/globals.css` 的作用域样式覆盖。
- 不改 API 调用、状态管理、异步时序、权限判断和弹窗交互。
- 保留紧凑侧栏 + 详情布局；创建项目继续使用按需弹窗。
- 统一页面背景、顶部导航、项目列表、项目详情、审批区和弹窗的圆角、边框、阴影与间距。
- 通过管理页测试、TypeScript 检查、Next 生产构建及静态浏览器截图复核响应式布局。

## 设计方向

1. 采用中性灰蓝页面底色和白色主卡，降低浅蓝色块的面积。
2. 顶部视图切换改为轻量 segmented control，减少两个完整卡片造成的视觉噪声。
3. 左侧项目列表使用紧凑的分组层级和轻量选中态，项目详情保持单一主卡。
4. 指标、编辑区和审批区使用细分层级，不重复叠加重边框。
5. 保存是详情编辑区的主操作；知识库、迁移、恢复是次级操作；删除保持低强调危险入口。
6. 375px、1024px、1440px 下保持无横向溢出和可用的内部滚动。
